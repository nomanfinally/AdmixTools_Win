Native Windows x64 development installer for the AdmixTools compatibility port.

Download **AdmixTools-8.1.0-windows-x64.msi** from Assets below. The single MSI
installs offline and includes 37 supported native tools, their runtime DLLs,
Graphviz and Ghostscript. It offers a destination folder, optional user PATH,
repair and uninstall. Python, WSL, MSYS2 and a compiler are not required on the
destination computer. Target: x64 Windows 10 version 1903 or later / Windows 11;
the recorded lifecycle tests used Windows x64 build 26300.

The package is **unsigned** and Windows may display an unknown-publisher warning.
Verify the SHA256 checksum and download from this repository's release page.

MSI SHA256:
`ffacdf6f019320758cdfda11057054a98d9b4ce41060769d086a43f0a3231310`

Assets also include the portable ZIP, sanitized payload/provenance manifest,
checksums, validation results, and a matching sources ZIP. The source bundle
contains the tagged project, actual patched argp sources, and 38 matching MSYS2
dependency source packages with upstream sources and build recipes. Each
dependency retains its own license; source and binary archives carry the relevant
notices and source-package information.

This is a **pre-release**, not certification of numerical parity for the whole
suite. The exact MSI passed both PATH-choice lifecycle cases, all 506 installed
file hashes, repair, uninstall, user-data/PATH preservation, and automatic PDF
rendering without AdmixTools on PATH. The existing 35-case integration suite
matched the recorded pristine Linux reference: 70 normalized streams and 18
generated files, with exact binary round trips.

Upstream baseline: `67bc219174a109951a9434e0a383ec464fb140ee` (AdmixTools 8.1.0).
The Windows port preserves upstream calculations; packaging adds no scientific
optimizations. Full per-tool hard audits, a live wizard/accessibility/high-DPI
walkthrough, a separate clean-machine test and cross-version MSI upgrade testing
remain incomplete. Optional interpreter workflows and the unbuildable upstream
`qpfmvmix` target are not included.

See [Windows setup](https://github.com/nomanfinally/AdmixTools_Win/blob/main/README.WINDOWS.md)
and [recorded installer validation](https://github.com/nomanfinally/AdmixTools_Win/blob/main/packaging/windows/VALIDATION.md).
Future installers can be rebuilt with `build-installer-windows.ps1 -Rebuild`
and a higher numeric package version; see the packaging guide in the source.
